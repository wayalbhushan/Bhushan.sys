# Bhushan.sys ⚡

A high-performance, single-page developer portfolio featuring a dark, hacker-inspired aesthetic. Designed to reflect the brand of a "black-box systems engineer," this portfolio showcases enterprise-level backend engineering, low-level C++ architectures, and offensive security research.

## 🚀 Features

- **Interactive Terminal Widget**: A sleek, draggable, and interactive terminal overlay that simulates a boot-up sequence and responds to basic command-line inputs (e.g., `help`, `whoami`, `clear`).
- **Live SVG Data Flows**: Animated, SVG-based topological diagrams that illustrate complex system architectures such as the **Aegis DPI** engine and **O(1) Post-Quantum Cryptography** authentication gateways.
- **Glassmorphism & Neon Accents**: A heavy glassmorphic UI using backdrop filters and deep translucent backgrounds, accented by dynamic green and cyan neon glows.
- **Magnetic Micro-Animations**: Buttons and project cards utilize custom magnetic-lift physics and subtle 3D perspective tilts for an incredibly tactile user experience.
- **Custom Cyber Cursor**: A custom-engineered viewport cursor with smooth trailing glow mechanics that react to interactive DOM elements.
- **Fully Responsive**: Fluid scaling and flex grids ensure the portfolio looks seamless on 4K monitors, tablets, and mobile devices.

## 🛠️ Technology Stack

- **Core**: HTML5, CSS3, JavaScript (ES6+)
- **Design Methodology**: Vanilla CSS with customized variable tokens, zero CSS frameworks (no Tailwind/Bootstrap dependency).
- **Icons**: Devicon & FontAwesome.
- **Forms**: Integrated with FormSubmit for seamless, backend-free contact transmission.

## ⚙️ Running Locally

Because this project is built entirely with vanilla web technologies, no build step or package installation is required. 

1. Clone the repository:
   ```bash
   git clone https://github.com/wayalbhushan/Bhushan.sys.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Bhushan.sys
   ```
3. Open `index.html` in your favorite web browser, or use a local development server (like VS Code Live Server or Python's HTTP server) for the best experience:
   ```bash
   python -m http.server 8000
   ```
   Then visit `http://localhost:8000`.
